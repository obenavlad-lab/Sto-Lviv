# СТО24 Львів — готовий сайт

Усі файли лежать в одній папці. Збірка та встановлення пакетів не потрібні.

## Завантаження
1. Розпакуйте stolviv-ready.zip.
2. Завантажте всі файли з архіву в корінь репозиторію stolviv із заміною старих. Сам ZIP завантажувати не потрібно.
3. index.html, service.html, suspension.html, diagnostics.html, maintenance.html, style.css, main.js та п’ять JPG мають лежати поряд.
4. Збережіть зміни в гілці, з якої вже публікується ваш GitHub Pages, і дочекайтеся завершення публікації.
5. Відкрийте https://obenavlad-lab.github.io/stolviv/ і оновіть сторінку через Ctrl+F5.

## Що готово
- Чотири окремі сторінки послуг із прямими переходами з карток, підвалу та навігації між послугами.
- Українські тексти, блоки складу робіт, ознак, цін, етапів і питань.
- Телефонний запис, посилання на карту та Instagram.
- Наявні паралакс, поява блоків, переходи між сторінками, зміна теми, мобільне меню та FAQ.
- Видимий фокус, підтримка клавіатури й зменшення руху, читабельність без JavaScript.
